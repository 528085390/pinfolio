# 阶段一：资产 ↔ 监控/主机双向联动与桌面端全局快速录入便签 设计规范

**日期**：2026-11-06  
**分支**：`feat/phase1`  
**工作区**：`pinboard/.worktrees/feat-phase1`

---

## 1. 目标与背景

当前 pinfolio 的资产台账、观测台、主机指标和便签各模块功能成熟，但存在两处明显体验断层：
1. **资产与运维观测割裂**：资产页登记了 VPS 服务器与自建节点，观测台与主机页有这几台机器的实时探活与硬件指标，但三者缺乏数据互通，需要用户在三个页面之间来回跳转比对。
2. **随手记便签路径较长**：桌面客户端最小化在托盘时，想要随手记一笔想法或服务器临时凭据，必须呼出主窗口、等待加载、切到便签页、聚焦输入框再打字。

阶段一通过两项特性解决上述问题：
- **功能 A：资产 ↔ 监控与主机指标双向联动**（Web / 服务端）
- **功能 B：桌面端全局快捷键快速录入便签**（Electron 桌面端）

## 2. 功能 A：资产 ↔ 监控与主机指标双向联动

### 2.1 数据存储约定
- 资产的数据结构在 `assets` 表中已有 `custom TEXT NOT NULL DEFAULT '{}'`（JSON 字典），已支持存储自定义扩展属性并在 API 中序列化/反序列化。
- 我们在 `asset.custom` 中定义两个规范字段：
  - `hostId?: string`：关联的主机 ID（如 `aws`, `az`, `oj`, `os`, `ox`），与 `data/metrics.json` 中的 `hosts[i].id` 严格对应。
  - `monitorIds?: number[]`：关联的观测项 ID 数组（如 `[19, 20, 22]`），与 Kuma 监控项 ID 对应。
- 向后兼容：`custom` 原有字段（如 `ip` 等用户自定义字段）完全保留，读写时只合并或更新这两个键。

### 2.2 资产抽屉（`AssetDrawer`）交互增强
1. **编辑表单（`BasicFields` 或新增 `asset-drawer/LinkedTelemetry.tsx`）**：
   - 增加「运维观测关联」折叠或独立小节：
     - **关联主机**：下拉选择框，展示系统中当前配置的主机列表（读取 `/api/hosts` 提取 `id` 和 `label`），支持「无」与指定主机。
     - **关联观测项**：多选下拉框或勾选项，展示系统中当前可用的观测项（读取 `/api/monitors` 提取 `id`, `name`, `group`, `status`），支持多选。
     - **智能推荐（Auto-Suggest）**：当用户新建资产或编辑未绑定的资产时，若资产名称与某个主机 ID 或观测项组名一致（忽略大小写），显示「检测到匹配主机/观测项，一键填入」的小链接。
2. **抽屉详情展示态**：
   - 若关联了主机：
     - 展示该主机的实时状态卡片：在线/离线徽标、CPU 使用率、内存使用率、根分区磁盘占比、负载（Load 1/5/15）。
     - 提供「跳转到主机监控」快捷按钮（点击跳转 `/hosts` 并聚焦该卡片）。
   - 若关联了观测项：
     - 列表展示关联的每个观测项：名称、当前状态小圆点（UP 绿 / DOWN 红 / PENDING 灰）、延迟 ping ms、24h 可用率以及最近 20 拍心跳色条。
     - 提供「立即观测」操作按钮（触发 `POST /api/monitors/:id/check`）以及「跳转到观测台」链接。

### 2.3 观测台与主机页反向联动
1. **观测台详情抽屉（`MonitorDrawer`）**：
   - 详情中增加「关联资产」字段：若某资产的 `custom.monitorIds` 包含当前观测项 id，或资产名称匹配监控组短名，展示资产名称标签，点击可直接打开该资产的抽屉。
2. **主机卡片（`HostCard`）**：
   - 标题栏右侧若检测到关联资产，显示「🔗 资产：`<name>`」，点击快捷定位或打开该资产。

## 3. 功能 B：桌面端全局快速录入便签

### 3.1 核心架构
- 基于 Electron 的 `globalShortcut` 注册全局热键：默认 `CommandOrControl+Alt+N`（Windows 上为 `Ctrl+Alt+N`）。
- 托盘右键菜单（`tray.ts`）同步增加菜单项：「快速记便签 (Ctrl+Alt+N)」。
- 独立创建极简浮动窗口（`QuickNoteWindow`）：
  - 尺寸：540 x 240，无边框（`frame: false`），圆角阴影，背景深色 `#111315`，不留白边。
  - 属性：`alwaysOnTop: true`, `skipTaskbar: true`, `resizable: false`, `center: true`（或屏幕纵向 28% 位置）。
  - 生命周期：应用就绪后预创建或首次按键延迟创建，`close` 拦截为 `hide()`；按下快捷键时若隐藏则 `show() + focus()`，若已可见则隐藏。
  - 失焦处理：浮窗挂载 `blur` 事件监听，失去焦点时自动 `hide()`。

### 3.2 浮窗内容与保存逻辑
- 窗口可加载 `${targetUrl}/quick-note` 独立轻量路由或由 Electron 本地加载一段精致干净的 HTML。
  - 为保持和桌面端一致的免密会话与即时 API 连通，前端提供轻量路由 `/quick-note`（或由桌面端内嵌 HTML + `fetch` 发送到 `targetUrl/api/notes`）。
  - 支持快捷键：
    - `Ctrl + Enter` / `Cmd + Enter`：保存并入库。
    - `Esc`：关闭浮窗。
  - 内容特性：
    - 多行文本输入框，随手记文本；
    - 输入 `#标签` 时动态解析预览；
    - 保存状态反馈：成功时显示绿勾小提示并自动关闭，同时向主窗口广播或通知主窗口刷新便签列表；失败时显示错误原因且保留输入草稿。

## 4. 关键测试与非功能性约束
1. **测试隔离**：单测不能碰真实数据库，必须通过临时目录与 Mock。
2. **向后兼容**：老数据在没有 `hostId` / `monitorIds` 时完全正常，不崩不乱。
3. **性能零损耗**：快速录入窗口不占用过多内存，主窗口后台驻留平稳。
