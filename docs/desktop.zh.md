# pinfolio 桌面端

pinfolio 桌面端是基于 Electron 的 Windows 原生桌面套壳客户端。它直接连接核心网页端服务（默认直连本机 `http://127.0.0.1:7788/`），为便签、资产台账、观测台等功能赋予独立原生窗口、系统托盘常驻、开机自启、外链安全拦截以及自动更新等桌面原生能力。

**设计理念**：核心业务与数据始终由统一的 pinfolio 网页端驱动，桌面端专注提供优质的原生桌面交互体验。网页端与桌面端实时保持同一份数据，杜绝两套数据库不同步的问题。

---

## 一、安装与启动

1. 在 GitHub [Releases](https://github.com/528085390/pinfolio/releases) 页面下载最新的安装包 `pinfolio-Setup-<version>.exe`。
2. 双击安装程序，按照向导选择安装目录（默认安装在 `%LOCALAPPDATA%\Programs\pinfolio`）。
3. 安装完成后会自动创建开始菜单项和桌面快捷方式，并直接启动。

### SmartScreen 提示说明

由于本项目为开源个人项目，暂未购买商业代码签名证书，在 Windows 上首次下载或运行时，Windows Defender SmartScreen 可能会弹出提示：

> **Windows 已保护你的电脑**  
> Microsoft Defender SmartScreen 阻止了无法识别的应用启动。

**解决办法**：点击窗口中的 **「更多信息」**，随后点击右下角出现的 **「仍要运行」** 按钮即可。每个发布的安装包均会在 GitHub Release 中附带 SHA-512 校验和，可在 PowerShell 中通过 `Get-FileHash -Algorithm SHA512 pinfolio-Setup-*.exe` 核对文件完整性。

## 二、日常使用特性

### 1. 核心网页端直连
桌面端默认直连本地运行的 pinfolio 服务（`http://127.0.0.1:7788/`）：
- **本地环境**：确保本地已通过 `start.cmd` 启动 pinfolio 网页端（后台隐藏运行）。双击桌面端即可瞬间载入本地已有的所有便签、资产、监控与邮件。
- **登录状态记忆**：首次进入若启用了访问密码，只需输入一次主密码登录；Chromium 会安全持久化会话凭证（30 天有效期），后续打开桌面端自动保持登录。
- **多端同步**：在桌面端所做的每一次便签创建、编辑、归档或删除，与浏览器访问网页端实时同步，完全一致。

### 2. 离线等待与自动重试
如果在打开桌面端时核心网页端尚未启动，桌面端会展示专属的深色离线等待提示页面：
- 明确提示当前尝试连接的服务地址及启动方法（如运行 `start.cmd`）。
- 内置自动重连定时器，每隔 3 秒自动尝试重新连接；一旦网页端启动完成，无需任何多余操作，窗口自动刷新并进入主界面。
- 支持点击页面中央的「立即重试」按钮即时重试。

### 3. 目标服务灵活配置
除了默认直连本机的 `http://127.0.0.1:7788/` 之外，桌面端还支持连接到局域网其他主机或远程私有服务器：
1. **环境变量**：设置 `PINBOARD_WEB_URL=http://<你的服务IP或域名>:<端口>`（或 `PINBOARD_URL`）。
2. **配置文件**：在 `%APPDATA%\pinfolio\client-config.json` 中配置：
   ```json
   {
     "webUrl": "http://192.168.1.100:7788"
   }
   ```
优先级为：`PINBOARD_WEB_URL` 环境变量 > `client-config.json` > 默认回环 `http://127.0.0.1:7788`。

### 4. 单实例守卫
pinfolio 桌面端在操作系统中始终保持单实例运行：
- 重复双击快捷方式或打开安装包只会将焦点唤醒到当前已运行的主窗口，不会重复创建窗口或冲突抢占资源。

### 5. 窗口管理与系统托盘
- **点击右上角 ✕ 关窗**：窗口默认不会退出进程，而是最小化隐藏到系统右下角托盘区，保持常驻随时可用。
- **重新唤醒**：鼠标单击或双击托盘区的 pinfolio 图标，即可重新呼出并置顶主窗口。
- **托盘右键菜单**：
  - **显示 pinfolio**：呼出并聚焦主界面。
  - **刷新页面**：重新载入网页端界面。
  - **在浏览器中打开网页端**：一键调用系统默认浏览器打开当前连接的网页端 URL。
  - **开机自启**：点击可开启或关闭 Windows 开机随系统静默自启（基于注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`）。
  - **检查更新**：主动向 GitHub Releases 探测是否有可用新版本。
  - **退出**：彻底退出桌面端应用。

### 6. 外部链接安全处理
便签内容、资产备注或帮助文档中的外部网址（如 `https://...` 或 `http://...`）点击后会自动调用系统默认浏览器打开，不会在桌面端窗口内部跳转，保护桌面端运行上下文的安全性。

## 三、数据存储与备份

### 数据存放位置
由于桌面端采用客户端原生套壳架构，所有核心业务数据（便签、图片、资产台账、SQLite 数据库）均存放在核心网页端对应的服务目录下（如本机的 `data/` 目录），由统一的快照与备份机制管理。

桌面客户端本地仅存储桌面端运行环境与配置，位于当前用户的应用数据目录下：

```
%APPDATA%\pinfolio\
  ├── client-config.json     # 客户端可选配置文件（如自定义 webUrl）
  ├── window-state.json      # 窗口尺寸与屏幕位置记忆
  └── logs\
      └── main.log           # 桌面端主进程运行日志（按 1MB 自动滚动）
```

> 💡 **小技巧**：在资源管理器地址栏直接输入 `%APPDATA%\pinfolio` 并按回车，即可直达客户端日志与配置目录。

### 卸载策略
当通过 Windows「控制面板」或「设置 → 应用」卸载 pinfolio 桌面端时：
- NSIS 卸载程序只会删除位于 `%LOCALAPPDATA%\Programs\pinfolio` 的程序二进制文件和快捷方式。
- 网页端的核心数据完全不受任何影响，确保便签资产绝对安全。

## 四、自动更新机制

1. **静默探测**：桌面端启动 30 秒后，会在后台静默连接 GitHub Releases 检查新版本，避免冷启动时抢占系统网络资源。
2. **手动检查**：随时右键托盘图标点击「检查更新」。
3. **下载与提示**：
   - 检测到新版本时会弹出对话框告知新版本号并询问是否下载。
   - 确认后转入后台静默下载，并在任务栏图标显示下载进度。
   - 下载完成后弹出重启提示；用户点击「立即重启」即可一键安装并重新启动进入新版本。

## 五、常见问题排查

### 1. 窗口显示「等待连接网页端服务」？
- 桌面端依赖底层网页端提供业务支撑，请确认本机网页端服务已启动（双击 `start.cmd` 启动，或检查 `http://127.0.0.1:7788/` 是否可访问）。
- 若使用的是非默认端口或远程服务，请检查环境变量 `PINBOARD_WEB_URL` 是否配置正确。
- 网页端一旦正常启动，等待页面在 3 秒内会自动重连进入主界面，也可以直接点击「立即重试」按钮。

### 2. 误关了主窗口怎么找回？
- pinfolio 默认留在右下角系统托盘（可能收纳在托盘的小三角 ∧ 溢出区中）。
- 单击或右键点击托盘图标选择「显示 pinfolio」即可重新唤出。

### 3. 查看桌面端运行日志
- 打开 `%APPDATA%\pinfolio\logs\main.log` 查看日志，可了解服务目标地址探测、窗口加载、托盘与自动更新事件记录。
