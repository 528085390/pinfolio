# pinfolio 桌面端

pinfolio 桌面端是基于 Electron 的 Windows 桌面应用形态。与 Web / Docker 形态共用同一套底层服务与前端界面，免去配置 Node.js、pnpm、数据库和环境变量的步骤，双击安装即可在本地独立运行。

---

## 一、安装与启动

1. 在 GitHub [Releases](https://github.com/528085390/pinfolio/releases) 页面下载最新的安装包 `pinfolio-Setup-<version>.exe`。
2. 双击安装程序，按照向导选择安装目录（默认安装在 `%LOCALAPPDATA%\Programs\pinfolio`）。
3. 安装完成后会自动创建开始菜单项和桌面快捷方式，并直接启动。

### SmartScreen 提示说明

由于本项目为开源个人项目，暂未购买商业代码签名证书，在 Windows 上首次下载或运行时，Windows Defender SmartScreen 可能会弹出提示：

> **Windows 已保护你的电脑**  
> Microsoft Defender SmartScreen 阻止了无法识别的应用启动。

**解决办法**：点击窗口中的 **「更多信息」**，随后点击右下角出现的 **「仍要运行」** 按钮即可。每个发布的安装包均会在 GitHub Release 中附带 SHA-512 校验和，可在 PowerShell 中通过 `Get-FileHash -Algorithm SHA512 pinfolio-Setup-*.exe` 核对文件完整性。

## 二、日常使用特性

### 1. 本机自动免密
桌面端启动时会自动在回环地址（`127.0.0.1`）上随机分配端口并拉起内置服务，随后由 Electron 主进程向会话中自动注入免密认证 Cookie。
- 首次使用**无需**前往 `/setup` 页面设置主密码，直接进入便签主页。
- 认证仅对本机回环端口生效，未授权的外部网络请求仍会被严格拦截（返回 401）。

### 2. 单实例守卫
pinfolio 桌面端在操作系统中始终保持单实例运行：
- 重复双击快捷方式或打开安装包只会将焦点唤醒到当前已运行的主窗口，不会重复启动多个内置服务或抢占端口。

### 3. 窗口管理与系统托盘
- **点击右上角 ✕ 关窗**：窗口不会退出进程，而是默认最小化隐藏到系统右下角托盘区。此时后台的主机指标轮询、Kuma 状态探测、邮件轮询及自动快照仍会静默持续工作。
- **重新唤醒**：鼠标单击或双击托盘区的 pinfolio 图标，即可重新呼出并置顶主窗口。
- **托盘右键菜单**：
  - **显示 pinfolio**：呼出并聚焦主界面。
  - **开机自启**：点击可开启或关闭 Windows 开机随系统静默自启（基于注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`）。
  - **检查更新**：主动向 GitHub Releases 探测是否有可用新版本。
  - **退出**：安全停止所有后台任务与内置 HTTP 服务，释放端口与 SQLite 句柄并彻底退出进程。

### 4. 外部链接安全处理
便签内容、资产备注或帮助文档中的外部网址（如 `https://...` 或 `http://...`）点击后会自动调用系统默认浏览器打开，不会在桌面端窗口内部跳转，保护桌面端运行上下文的安全性。

## 三、数据存储与备份

### 数据目录位置

桌面端的所有运行时数据与配置文件均存放在当前 Windows 用户的个人应用数据目录下：

```
%APPDATA%\pinfolio\
  ├── data\
  │   ├── pinboard.db        # SQLite 主数据库（便签、资产、标签、指标等）
  │   ├── secret.key         # 敏感资产字段的 AES-256 加密密钥
  │   ├── uploads\           # 便签图片原图与缩略图存储目录
  │   ├── backups\           # 系统自动生成的全量备份归档
  │   └── audit\             # 长期健康归档数据
  ├── logs\
  │   └── main.log           # 桌面端主进程运行日志（按 1MB 自动滚动并保留 1 份备份）
  └── window-state.json      # 窗口尺寸与屏幕位置记忆
```

> 💡 **小技巧**：在资源管理器地址栏直接输入 `%APPDATA%\pinfolio` 并按回车，即可直达该目录。

### 卸载策略
当通过 Windows「控制面板」或「设置 → 应用」卸载 pinfolio 时：
- NSIS 卸载程序只会删除位于 `%LOCALAPPDATA%\Programs\pinfolio` 的程序二进制文件和快捷方式。
- **绝不会删除** `%APPDATA%\pinfolio` 中的数据目录，确保用户的便签、图片和配置安全保留。
- 重新安装新版本后会自动识别并无缝继承历史数据。
- 若需彻底清除所有本地数据，只需在卸载后手动删除 `%APPDATA%\pinfolio` 文件夹。

## 四、从 Web / Docker 迁移数据

如果你此前在 Linux / macOS / Docker 或本机的 Web 模式下运行 pinfolio，并希望将数据迁移到桌面端：

1. **退出桌面端**：右键系统托盘图标，点击 **「退出」**。
2. **复制关键文件**：
   从现有 Web 端的 `data/` 目录中，拷贝以下文件到桌面端的 `%APPDATA%\pinfolio\data\` 目录下：
   - `pinboard.db`（主数据库文件）
   - `secret.key`（**必须与数据库成对迁移**，否则资产中已加密的密码将无法解密）
   - `uploads/` 文件夹（如果便签中存有图片）
3. **重新打开桌面端**：启动 pinfolio 桌面端，所有的便签、标签、图片、资产台账与监控配置将立即恢复。

> ⚠️ **注意**：从桌面端往远程 Web / Docker 迁移时亦遵循同样规则。若迁移到外部服务器并通过网络访问，建议在设置页中设置访问密码。

## 五、自动更新机制

1. **静默探测**：桌面端启动 30 秒后，会在后台静默连接 GitHub Releases 检查新版本，避免冷启动时抢占系统网络资源。
2. **手动检查**：随时右键托盘图标点击「检查更新」。
3. **下载与提示**：
   - 检测到新版本时会弹出对话框告知新版本号并询问是否下载。
   - 确认后转入后台静默下载，并在任务栏图标显示下载进度。
   - 下载完成后弹出重启提示；用户点击「立即重启」即可一键安装并重新启动进入新版本。

## 六、常见问题排查

### 1. 启动时提示「连接失败」或窗口未出现？
- 打开 `%APPDATA%\pinfolio\logs\main.log` 查看日志。桌面端在冷启动时若遇到安全软件拦截端口，会自动进行最多 10 次的带超时重试。
- 检查是否有第三方网络防护软件强行拦截了 `127.0.0.1` 回环连接。

### 2. 误关了主窗口怎么找回？
- pinfolio 默认留在右下角系统托盘（可能收纳在托盘的小三角 ∧ 溢出区中）。
- 单击或右键点击托盘图标选择「显示 pinfolio」即可重新唤出。
